# Talent Pilot App Documentation

Talent Pilot App is the internal recruiting workspace. It is where Presales, PMO, Recruiters, Interviewers, HODs, Hiring Managers, and Tenant Admins execute recruiting work after the tenant has been configured.

## Purpose

The app keeps recruiting execution separate from Admin Center configuration and Candidate Portal self-service.

Internal users can:

- Create and review job requests.
- Claim workflow assignments.
- Review bench matching context.
- Publish jobs.
- Source and invite candidates.
- Track candidate pipelines.
- Schedule interviews.
- Submit feedback.
- Review final hiring decisions.
- Close job requests.

## Primary Work Areas

| Area | Purpose |
| --- | --- |
| Dashboard | Role-aware summary of current work and recruiting health. |
| My Work | Assigned tasks and claimed workflow items. |
| Job Requests | Create, inspect, route, and close hiring requests. |
| PMO Queue | Review routed requests and bench matching work. |
| Recruitment Queue | Manage sourcing-ready requests and active recruiter work. |
| Job Publishing | Manage job post publication and visibility. |
| Candidates | Inspect candidate records and candidate profile history. |
| Candidate Pipeline | Track applications by stage and status. |
| Interview Scheduling | Schedule and manage candidate interview rounds. |
| Interview Feedback | Complete assigned interviewer feedback. |
| Hiring Manager Review | Review final candidates and make outcome decisions. |
| Reports | Review tenant recruiting performance and operational metrics. |

## Role-Aware Navigation

Users should only see routes that match their roles and permissions. Tenant Admins can see broader operational access, but normal daily work should still happen in the correct workflow screens.

## Operational Boundaries

Use these boundaries:

- Admin settings belong in Admin Center.
- Candidate self-service belongs in Candidate Portal.
- Internal workflow execution belongs in Talent Pilot App.
- AI recommendations are advisory and should include evidence.
- Every sensitive transition should be auditable.
